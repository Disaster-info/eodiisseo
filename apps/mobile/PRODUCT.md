# Product

## Platform

adaptive

## Users
일반 시민 전체. 평소에는 내 지역 재난 알림을 받고, 재난이 발생하면 급하게 가까운 대피소와 가족·지인의 안전을 확인한다. 급박하고 불안한 상황에서 한 손으로 빠르게 판단해야 하는 사용 장면이 핵심이다.

운영자(`operator` 권한)는 별도의 운영 관리 화면에서 외부 API 수집 상태, 재난 데이터, 오류 로그를 점검한다.

## Product Purpose
"어디있어"는 공식 재난 정보를 내 위치와 내 사람들 기준으로 보여 주는 앱이다. 사용자가 "지금 내가 위험한지, 어디로 가야 하는지, 가족은 괜찮은지"를 빠르게 알 수 있으면 성공이다.

## Positioning
- **안심그룹**: 가족·친구·직장 그룹 구성원이 재난 영향지역 안에 있는지 한눈에 확인한다(영향지역 포함 / 밖 / 위치정보 미제공 / 판단 불가).
- **내 위치 기준 대피**: 현재 위치(GPS 또는 직접 선택)를 기준으로 가장 가까운 대피소를 반경을 넓혀 가며 찾고, 경로까지 바로 안내한다.

## Operating Context
- 재난 정보 출처: 기상청(특보·지진), 산림청(산불), 행정안전부(재난문자·대피소). 같은 재난은 하나로 합치되, 기관별 원문은 유지한다.
- 주요 흐름: 소셜 로그인(Google/Kakao) → 위치 동의 또는 수동 지역 선택 → 홈(내 지역 재난·날씨) → 재난 상세(AI 요약 + 원문) → 대피소 목록·상세·경로 → 안심그룹(초대 코드로 참여, 최대 10명) → 체크리스트 → 행동요령 챗봇 → 알림 설정·이력.
- 기능 명세는 FS-xxx 코드(예: FS-DATA-001, FS-SHELTER, FS-CHAT-001)로 관리하며 코드 주석에 표기한다.

## Capabilities and Constraints
- Expo SDK 57 / React Native / Expo Router. 현재 프론트엔드만 있으며 `src/data/mock.ts` 목업 데이터로 동작하고, 백엔드 API 연동은 아직 하지 않았다.
- 디자인은 iOS·Android 공통으로 하나만 쓴다. `adaptive`는 OS마다 디자인을 따로 만든다는 뜻이 아니라, 두 OS의 기본 보장(세이프 에어리어, 뒤로가기 제스처, 동작 줄이기 등)을 모두 지킨다는 뜻이다.
- 다크/라이트 테마를 지원한다(`userInterfaceStyle: automatic`, 앱 내 테마 설정).
- 재난 유형: 지진, 호우, 산불. 위험수준: 정보 < 주의보 < 경보. 상태: 발생, 진행중, 종료, 해제.
- AI 요약 처리상태: 완료, 대기, 실패, 갱신 대기(원문이 바뀌어 요약이 최신이 아님).
- 대피소 검색 최대 반경은 5km(시스템 정책값)이며, 거리는 지역 기준점에서 잰 직선거리다.
- 정해진 용어: 안심그룹, 영향지역, 대피소, 행동요령, 운영 관리.

## Evidence on Hand
- 실제 데이터는 아직 없다. 지금 보이는 재난·대피소·그룹·날씨 데이터는 모두 목업이며, 실서비스 데이터처럼 소개하지 않는다.
- 사용 후기, 사용자 수, 제휴·인증 같은 근거는 없으므로 만들어 내지 않는다.

## Product Principles
1. **공식 정보만 보여 주고, 없는 값은 지어내지 않는다.** 공식 등급, 수용인원, 소요시간이 없으면 비워 두고 "없음"이라고 알린다.
2. **불확실하면 불확실하다고 말한다.** 수집 실패(stale), 요약 실패나 갱신 대기, 위치 미제공, 판단 불가 상태를 숨기지 않는다.
3. **위급할 때는 판단과 행동이 먼저다.** 지금 위험한지, 어디로 가야 하는지, 가족은 괜찮은지를 가장 적은 단계로 보여 준다.
4. **AI는 원문을 대신하지 않고 돕는다.** 요약 옆에는 항상 기관 원문과 출처를 함께 보여 준다.

## Accessibility & Inclusion
일반 시민 전체가 대상이므로 고령자도 포함된다. 시스템 글자 크기 확대, 스크린리더 레이블, 색에만 의존하지 않는 위험수준 표시(아이콘과 글자를 함께 표시)를 기본으로 지킨다. 별도로 정한 인증 표준은 없다.
