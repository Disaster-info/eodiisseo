A. 기능별 묶음위치 · 알림 · 화면 · 계정 · 운영자
  • 비슷한 설정끼리 5개 묶음, 모든 행이 같은 높이
  • 테마는 현재 값만 보이고 누르면 선택 시트
  • 소셜 연결·로그아웃·탈퇴를 '계정' 하나로
iOS·Android 설정 앱과 같은 구조라 익숙함. 길이는 현재보다 짧지만 여전히 한 화면을 조금 넘음.
B. 요약 + 묶음프로필 아래 상태 태그
  • 위치 동의·알림·관심지역 상태를 프로필 아래 태그로 한눈에
  • 위치와 알림을 한 묶음, 테마는 행 안의 작은 세그먼트(바로 바꿈)
  • 로그아웃·탈퇴는 맨 아래 따로
상태를 가장 빨리 파악. 태그와 아래 목록에 같은 정보가 두 번 나옴.
C. 2단계 구조메인은 분류만, 상세는 다음 화면
  • 메인 화면이 스크롤 없이 한 화면에 끝남
  • 각 행 아래에 현재 상태 요약
  • 두 번째 화면 예: '계정 관리' (로그인 정보·소셜 연결·로그아웃·탈퇴)
가장 깔끔하지만 위치 동의 같은 스위치를 켜고 끄려면 한 번 더 들어가야 함.
